# The Surface

A web application built for the **NASA Space Apps Challenge 2026**. The web application explains what is wildfire, how it is born, its global impact, has built-in features that alerts registered users about wildfire breakouts and lets the user plan out their day based on their location's weather information.

**Challenge:** Harmonization of MODIS and VIIRS Hotspots 

## Documentation Video 
[Watch the 240 seconds demo video](https://youtu.be/ac1AEY_QsIo)

## Features
- Primary information section about wildfires
- A report analysis on wildfire's impact on economy
- Live hotspots tracking system
- Alerting system to notify users about wildfire breakouts and predictions
- Chatbot system for users to plan out their day based on their location

## Run the Project Locally 
### Requirements list
- [Nodejs]( recent LTS version)
- [Git]
- Code editor such as [VS Code]
### Steps 
- Clone the repository
- Install the dependencies
- Start the development server
- Open the local host link in your browser
### Commands 
- 'npm run build'
- 'npm run preview'
In order to close the server use keyboard shortcut Ctrl + c
